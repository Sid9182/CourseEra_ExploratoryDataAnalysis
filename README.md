# CourseEra_ExploratoryDataAnalysis

# ExData_Plotting1

This repository contains the R code and documentation files for the Coursera "Exploratory Data Analysis" Course Project 1.

## Dataset
This assignment uses data from the **UC Irvine Machine Learning Repository**, specifically the "Individual household electric power consumption Data Set".

* **Dataset URL:** [Electric power consumption](https://d396qusza40orc.cloudfront.net/exdata%2Fdata%2Fhousehold_power_consumption.zip)
* **Description:** Measurements of electric power consumption in one household with a one-minute sampling rate over a period of almost 4 years.
* **Dates Used:** 2007-02-01 and 2007-02-02.

## Files
For each of the four plots required, there is an R script and a corresponding PNG image:

* **Plot 1:** `plot1.R` generates `plot1.png`
* **Plot 2:** `plot2.R` generates `plot2.png`
* **Plot 3:** `plot3.R` generates `plot3.png`
* **Plot 4:** `plot4.R` generates `plot4.png`

## How to Run
1.  Download and unzip the dataset into your working directory.
2.  Open RStudio and set your working directory to the folder containing the data.
3.  Source each file to generate the plots:
    ```R
    source("plot1.R")
    source("plot2.R")
    source("plot3.R")
    source("plot4.R")
    ```
